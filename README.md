# Repo Files Description
To run the code you have to download all of the associated files -> the templete taken is a bootstrap templete .
- index.html: the code that have the home page from where we can access all other pages.
- arabic.html: the page that contain arabic books to be sell, this page will be accessed from index.html (home page)
- english.html: the page that contain english books to be sell, this page will be accessed from index.html (home page)
- sample-inner-page.html : this page come with the bootstrab templete , it contains the sections that will be the same on all pages like the website menu bar and the footer that contain some info .
- assets.zip: the folder contains the files associated with the bootstrap templete like img folder which i add to it images for my project. 
- README.md: Project and repo description.
